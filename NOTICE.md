# Scope of the MIT code license

The root MIT license covers the original software distributed in this repository.
It does not relicense datasets, model weights, manuscript files, external dependencies,
or any third-party implementation. No third-party implementation is bundled here.
Dependencies are installed separately under their own licenses.

The RFCFormer comparison is the authors' range-profile adaptation of the architecture
described by Ji et al., DOI 10.1109/TGRS.2025.3575484. It is not the original authors'
reference implementation, nor a claim of reproducing their original four-parameter task.

The private two-dimensional PE solver is not included. Cached simulated propagation
outputs are separate data, not the solver source. COARE, raw ERA5 downloads, external
measured datasets, author correspondence, and manuscript/reviewer PDFs are not bundled.

Dataset and checkpoint redistribution terms must be taken from their separate deposit.
Publishing this code does not by itself grant a license to those separate artifacts.
